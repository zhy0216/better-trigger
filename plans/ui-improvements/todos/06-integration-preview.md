# 集成验收与本地源码预览

优先级：P2。模型：flash。前置依赖：02-runs-list、03-tasks-dashboard、04-schedules、05-run-details 全部完成并合并（01 的依赖由它们传递）。一个 worktree、一个最终 commit；本任务串行执行。

## T1 · 合并后整仓校验与必要修复

- **工作**：基于全部 UI 更改合并后的源码执行整仓校验，检查共享 shell 和各页协作中的导航、环境、认证、分页和操作反馈；仅修复本轮引入的集成问题。需要 PostgreSQL 的检查使用仓库当前约定的独立测试资源，不能使用用户业务数据库；遵循 `agent.md` 使用 Bun。
- **预计修改文件**：各 UI 实现/对应测试中的必要集成修复、`plans/ui-improvements/plan.md` 的实施验收记录；此时相关文件已无并行拥有者。不修改 API/数据库/SDK 协议，不为通过校验扩大到无关重构。
- **验收**：从仓库根运行 `bun run typecheck`、`bun run lint`、`bun run build`、`bun run test`；不用 `bun run --bun test` 强制解释器。记录命令、真实结果和必要的失败/环境缺失说明；未运行不计作通过。新增行为回归针对实际问题，不添加样式快照。每次修复后重跑受影响检查，全部通过后不无故重复。
- **前置依赖**：02-runs-list、03-tasks-dashboard、04-schedules、05-run-details 全部合并。

## T2 · 从合并源码启动本地 UI

- **工作**：重新检查本地 daemon、Compose 和端口状态；优先使用本次源码的 Vite 开发预览连接本地 daemon，绑定 loopback 并记录实际端口。daemon 未运行时可按根 README 沿用用户已有本地启动授权启动 Compose，保留容器卷，不清空/重建业务数据。若使用嵌入 UI 容器，先构建包含本次变更的镜像，验证实际入口资源来自新构建。
- **预计修改文件**：`apps/web/README.md` 中必要的本地预览说明；`plans/ui-improvements/plan.md` 验收记录。运行时进程和隔离验证资源无需加入业务源码；不提交缓存、构建产物或数据库文件。
- **验收**：地址可在本机浏览器打开，能够确认渲染的是合并后的 UI；记录具体地址、启动方式、后端连接状态及源码版本。端口冲突时选择可用端口并如实报告，不终止用户未知进程；旧容器页面不能充当新 UI。数据库/容器卷保持，不触发真实业务任务；不发布远程站点、不 git push。
- **前置依赖**：本文件 T1；02-runs-list、03-tasks-dashboard、04-schedules、05-run-details 全部合并。

## T3 · 浏览器矩阵与交互回归

- **工作**：对 T2 的实际新 UI 完成 390×844、768×1024、1440×960 检查，补充 375px、200% 缩放、深/亮主题和 comfortable/compact 边界。真实 API 检查核心页面；难以安全制造的失败、空态、长内容和写操作使用隔离 fixture，并明确记录数据来源。
- **预计修改文件**：受发现问题影响的 UI/行为测试；`plans/ui-improvements/plan.md` 验收记录，可将截图保存在 `plans/ui-improvements/evidence/`。fixture 只用于隔离验证，不接入产品数据路径。
- **验收**：完成以下矩阵并记录结果：Runs 有数据/首次空态/筛选无匹配/加载更多失败、联合筛选清除、live 暂停恢复、详情返回和前进后退；Tasks/Schedules 正常/长名称/空数据/次要数据不可用、开关成功/回滚/pending、环境切换不闪回旧数据；Run 多层 span/长 payload/失败 stack/无日志/历史分页错误、滚动暂停与跳到最新、复制成功/失败、取消重试。Shell 完整键盘流程、导航/设置 Escape 和焦点恢复、缩放后控制可达。页面无水平溢出，时间轴/大代码块可以内部滚动；无新增 console error。普通必要文字与控件焦点对比度有真实测量证据，不能仅凭视觉判断。
- **前置依赖**：本文件 T2；本文件 T1 产生的必要修复已验证。

## T4 · 交付可复查证据与访问地址

- **工作**：整理主要页面桌面/移动截图、浏览器矩阵、校验命令结果、已知限制及新 UI 本地地址；在 plan 的实施验收记录填入真实结果，必要时更新 web README 的启动步骤。检查本次最终 commit 仅含必要修复、文档/证据，不含测试秘密或业务数据。
- **预计修改文件**：`plans/ui-improvements/plan.md`、必要的 `plans/ui-improvements/evidence/`、`apps/web/README.md`。
- **验收**：用户能直接打开本次源码的预览；文档写清后端可用状态和实际端口，区分 live API 截图与 fixture 验证。未通过、未执行及环境限制均明确说明，浏览器错误页不计作 UI 截图。没有写用户业务数据库、清理卷、远程部署或推送。最终记录覆盖所有前述验收，不预填成功。
- **前置依赖**：本文件 T1、T2、T3。
